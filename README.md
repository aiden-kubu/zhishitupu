# 知识图谱系统

Vue 3 + TailAdmin + Spring Boot + MySQL 8，本地开发项目。

## 从当前开发进度继续

**先阅读 [接手开发与数据库恢复](database/README.md)。** 仓库包含脱敏数据库与原始资料压缩包，可还原当前实际开发数据，无需重新上传、识别 PDF。

- 9 个知识库、610 个知识点、844 条关系。
- 文档解析、OCR、知识抽取、AI 自动命名/分库/归入已有库、AI 对照原文复审后自动入库。
- 2D / 3D 图谱、知识问答、AI 搜索补全、处理与复审记录、知识统计和模型管理。
- 已完成新一轮管理页面、按钮、上传弹窗、手机和暗色主题优化。

模型密钥不随数据库发布。恢复后可直接浏览已有知识；继续识别和问答需要在系统设置填写自己的模型密钥并启用模型。
