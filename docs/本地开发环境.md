# 本地开发环境（2026-09-13）

项目位置：`E:\知识图谱`。

双击根目录 `start-dev.cmd` 启动，浏览器访问 http://127.0.0.1:5173 。双击 `stop-dev.cmd` 停止。服务在后台运行，关闭启动窗口不会停止服务。

前端修改后自动更新。后端修改后，先停止，再在项目目录执行 `powershell -ExecutionPolicy Bypass -File .\start-dev.ps1 -Build`；此命令执行后端测试、打包并启动。

## 运行环境

- Java：Eclipse Temurin JDK 17，已安装到 `C:\Program Files\Eclipse Adoptium`。
- Maven：使用仓库的 `mvnw.cmd` 自动管理。
- Node.js：使用本机已安装版本，前端依赖已安装。
- MySQL：复用 `F:\BTceshi\BtSoft\mysql\MySQL8.0` 的程序，运行独立实例，仅监听 `127.0.0.1:13306`。
- 数据库：`knowledge_graph`，项目账号 `kg_dev`；密码保存在被 Git 忽略的 `knowledge-graph/backend-java/src/main/resources/application-local.yml`。
- 数据与上传文件：`C:\Users\Administrator\.knowledge-graph-dev`，应备份整个目录，不要删除。
- 服务日志：项目 `.local/logs`；数据库日志位于上述数据目录的 `logs/mysql.log`。
- 后端端口 8080，前端端口 5173，均仅供本机访问。

独立数据库不依赖现有 3306 实例的数据与密码。新库没有 PHP 遗留表，本地配置跳过 V2 旧数据迁移，执行 V1/V3/V4/V5。V3 已修复空库判断，首次启动可完整生成 TCP、UDP 和对比关系，重复启动不重复插入。

本机 Java 的 Unix 域套接字使用专门的 ASCII 临时目录；启动脚本通过 `JAVA_TOOL_OPTIONS` 设置。直接运行 Maven 时也应设置此选项：`-Djdk.net.unixdomain.tmpdir=C:/Users/Administrator/.knowledge-graph-dev/tmp`。

AI 问答与抽取需要在系统设置中填写模型地址、模型名和 API Key。2026-09-13 已附脱敏数据库与原资料快照，其他电脑请按 [接手开发说明](../database/README.md) 恢复；快照不含可用模型密钥，需自行配置。

`.local`、数据库密码和构建产物均不提交 Git。启动脚本依赖本机 `.local/runtime.json`，不是其他电脑的一键安装程序。
