# UI 布局与交互规范

2026-09-13，依据用户提供的 TailAdmin 参考截图重新调整。参考的是内容宽度、分组和操作层级；模型能力及任务状态必须来自本项目真实数据。

## 布局

- 知识库、处理中心、AI 复审、数据洞察、系统设置统一使用居中最大 1280px 内容区。宽屏避免表单和卡片横向拉得过长。
- 图谱继续占用整个工作区；助手面板可收起。导航展开 240px、折叠 76px，小于 1280px 使用抽屉导航。
- 页面标题与描述在左，页面动作在右；全局搜索、导入资料保留在顶栏。页面不重复放置导入入口。
- 知识库使用概览和双列卡片；复审页分为资料概况、筛选、候选、AI 判断依据和可展开原文证据。
- 洞察页桌面左列为知识类型和未关联知识，右列为关联排行，避免不同高度卡片被拉伸留白。

## 操作与内容

- 主要操作使用品牌色，次要操作使用描边，编辑和删除使用有名称的图标按钮。统一按钮尺寸、圆角、图标盒和键盘焦点。
- 上传先选文件，再选择整理方式。默认 AI 自动整理，支持拖放、替换、移除，以及即时格式/大小提示。
- 系统设置先显示实际模型配置概览，再显示用途说明和模型服务。配置状态与连接测试结果分别表达；修改模型后旧测试结果失效。
- 文件存储、图谱显示参数收在默认折叠的“高级设置”。它们是可选偏好，不是导入资料的前置步骤。
- AI 复审按最新业务决策自动完成并入库，页面只展示结果与证据，不能重新引入人工确认入库按钮。
- 长原文、文件名和连接地址必须在窄屏换行；不能通过隐藏横向溢出来掩盖内容被裁切。
- 2D 图谱连线使用有效的主题描边。节点名称按选中、悬停、关联优先显示并避让；关系标签只展示与焦点有关且有空间的部分，完整名称仍可通过悬停查看。

## 维护检查

修改后检查桌面和 390px 窄屏、明暗主题、导航折叠、弹窗退出、下拉筛选、文件替换和错误恢复。统计与图谱使用真实接口；不得填充演示数字或把缺失数据伪装成正常状态。
