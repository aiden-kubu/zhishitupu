## 总控共用边界

1. W1 先交付各领域的只读事实、来源证据和未执行草稿；不得把现有写端点直接当模型工具。完整流程执行能力仍需后续统一操作执行器与领域校验，不能把只读基础版宣称为最终完整模块。
2. 系统事实、原文事实、模型解释、操作建议分别表达。AI 结论不能替代人工核验、正式判分或数据库提交回执。
3. 公共 `AgentTask / ToolResult / AgentResult / ActionProposal / ObjectRef`、调度器、公共路由、整体助手界面与迁移编号由总控统一。领域只扩展自己的输入和成果，不建立另一套调度状态。
4. 输入对象标识由服务端重查；资料与检索范围不得静默扩大。对象没有真实版本号时应说明限制，不能用快照哈希声称拥有并发写保护。
5. 学习教练负责规划、讲解和练习；测评分析负责正式题卷、判分与进度凭证。两者不得同时修改 `LearningPathService`；路径版本、评分和阶段完成规则由总控先确定接口与修改顺序。
6. 保留临时聊天不持久化的既有决策。需要持久化的任务、业务草稿、版本及执行回执，与聊天原文分开处理。
7. 每个子任务只能修改被指派的文件，不能自行启动其他子任务或进入 W1。本轮不合并、不部署、不连接业务数据库、不调用项目真实模型服务。
