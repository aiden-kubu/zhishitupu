# I1 网站只读信息架构与页面草图

日期：2026-09-27。仅页面方案，无前端实现、路由修改、网站发布或截图冒充。以下是 I5/I6 的设计输入，需另行批准实施。

## 1. 左侧导航：一个协作入口，复用领域页面

现有路由已经有 /assistant、/、/library、/processing、/review、/insights、/learning-path、/assessment、/learning-progress、/settings。I1 不新增路由；后续以一个「智能助手」组织跨领域任务，不再建立五套互不相通的聊天页。

建议侧栏分组：

```text
工作空间
  智能助手          /assistant       跨流程请求、任务进度、成果、证据
  图谱工作台        /                真实图谱及只读研究结果视图
知识建设
  知识库            /library         资料、归属、原文、处理状态
  处理中心          /processing      任务事实、错误、恢复建议
  质量治理          /review          复用 AI 复审入口，增加核查结果视图
  数据洞察          /insights         范围与统计口径、覆盖及缺口
学习空间
  学习路径          /learning-path    当前实际路径 / 未保存建议
  智能测评          /assessment       准备条件、候选、未核验旧记录
  学习进度          /learning-progress 旧进度事实；正式掌握度不可用
配置
  系统设置          /settings         独立管理权限；不通过助手改配置
```

「质量治理」为导航文案建议，不是已经重命名。「任务/成果」先作为智能助手内部页签；W1核心只保有调用方持有的内存运行对象，暂不承诺永久历史、跨设备同步或重启恢复。

## 2. 智能助手页面

```text
┌ 当前授权范围：验收库7101 / A、B       [只读预览] ┐
│ 目标输入：比较A/B并整理学习建议      [发起协作]  │
│ 运行状态：运行中 / 部分完成 / 失败 / 等待补充    │
├ 任务与依赖 ─────────┬ 成果 ──────────┬ 证据 ────┤
│ A研究 ✓            │ A/B结构化比较   │ 资料A      │
│ B研究 部分完成      │ 对应claim和缺口 │ chunk7401  │
│ 比较 → 质量 → 学习  │ 学习草稿 未保存 │ hash/时间  │
│ 测评候选 待依赖     │ 测评 正式不可用 │ [重读原文] │
├ [取消当前运行]  已产出成果保留；缺口与错误不隐藏 ┤
└ 草稿未执行 / 引用有效≠语义正确≠人工核验          ┘
```

提供任务模板：资料处理诊断、候选/引用核查、A/B研究、学习讲解与路径建议、测评准备。模板只安排所需角色，不要求每次五个Agent全部出动。A/B 是同一研究角色的两个独立任务，允许独立产出和失败；不是两个独立产品模块。

用户看到每个任务的职责、输入范围、直接依赖、状态、原始工具观察摘要、成果和缺口；不展示模型私有思维链。运行中可取消，但需说明取消不等于回滚。模型建议补充资料时显示明确待补充项；预算/超时失败不能伪装“分析完成”。

通用状态同时呈现：运行状态、工具结果OK/PARTIAL/ERROR、材料当前/陈旧/越界/缺失、覆盖本次请求/原成果全部、草稿执行状态。不要把这些压成一个绿勾。页面刷新无法恢复时提示“此运行未持久保存”，不能产生假历史。

## 3. 图谱工作台与研究成果连接

```text
┌ [现有全局视图] [研究结果只读视图]  范围/来源/观察时间 ┐
│ A命中 / B命中 / 共同命中       节点数≠全库节点数       │
├──────────────────────────────┬────────────────────┤
│ 7701 甲 ──R/7801──→ 7702 乙  │ 对象：真实ID、状态   │
│ 草稿节点：虚线、draft: 前缀   │ 来源：A/B、chunk/hash │
│ 不并入真实图谱统计            │ 缺口：截断/来源缺失   │
├ [2D/3D] [居中] [仅看路径]     │ [回到研究成果]        │
└ 没有“确认入库”、直接扩展、编辑/删除按钮              ┘
```

复用已有渲染能力，不以旧邻居API重新全库拉取替代已授权研究子图。现有 useGraphWorkspace 仅处理 node/depth/mode 并调用既有邻居读取，不能直接视为 Artifact/范围安全适配器。

后续需新增只读结果适配层：宿主确认运行/任务/成果归属 → 输出允许显示的真实 nodeId/edgeId 和真实 source→target → 前端高亮/路径/证据抽屉。路由上的 artifactId 只是定位线索，不是授权；服务端再次鉴权。双端不在范围内的关系不显示。

A/B按真实节点/边ID汇合，仍保留各自材料来源与coverage。物理来源计数用 documentId/chunkId/hash 去重；不同授权范围的引用ID仍保留原值，不能直接重写上游引用。相同hash但不同文档也不是同一来源。来源指针不够时显示“无可核验原文”，不能从节点名称猜造引用。

草稿建议单独叠层，临时draft标识不得冒充数据库ID，不参与真实统计；页面刷新无保存时可以消失并明确说明。草稿与真实图谱之间没有写入通道。

## 4. 领域页面展示边界

| 页面 | 只读主区 | 细节/状态 | 不提供或不声称 |
|---|---|---|---|
| 知识库 | 文档/知识库事实、可见归属 | 处理状态、正文单位/chunk、hash、失败/归档、分页覆盖 | 上传、改标签、归档恢复并非新的只读工具能力 |
| 处理中心 | 任务阶段、错误、确定性恢复评估 | 若未来执行可能调用模型/自动复审/入图等影响 | 不自动开始、重试、取消旧处理任务；助手运行取消与业务任务取消分开 |
| 质量治理 | 候选复审快照、来源核查、成果claim核查 | 候选状态 / AI判断 / 人工决定 / 实际导入结果四栏；请求覆盖和全部证据覆盖分开 | 引用当前不等于语义成立、人工审核或导入成功 |
| 数据洞察 | 有范围和口径的计数、孤立节点等 | 观察时间、截断、非事务一致快照提示 | 无历史数据不画趋势；局部结果不当全库 |
| 学习路径 | 左：服务端当前路径；右：未保存建议及差异 | 路径ID/指纹、阶段旧状态、分层讲解、非正式练习 | 不自动保存、不写visited、不进阶；version=2不是正式修订 |
| 智能测评 | 准备条件、两道未执行候选、旧记录 | 候选答案仅参考；legacy_unverified；正式服务不可用 | 无正式试卷/作答提交/判分/有效弱项/掌握度 |
| 学习进度 | 旧访问/旧分数/旧阶段状态，注明来源 | 正式评估区域显示不可用原因 | 不把旧访问量/旧高分画成正式掌握度 |
| 系统设置 | 仅独立配置管理页 | 授权人员管理模型/连接配置 | 助手不泄漏密钥、不代改设置 |

学习与测评共用布局示意：

```text
当前真实路径（只读） | 建议草稿（未保存） | 依据与差异
甲 current → 乙 locked | 目标/阶段建议      | 原路径指纹/资料引用
旧访问/90分 未核验     | 讲解/非正式练习    | 未覆盖论断/失败观察

正式测评：不可用（未接入正式评分服务）
测评候选：未执行草稿；不生成通过、掌握度或下一阶段解锁
旧记录：9102 90分 未核验；9101 100分 阶段未知
```

## 5. 体验验收要点

空数据、无授权、服务不可用、加载失败、部分完成必须分别可辨；不以空列表掩盖失败。窄屏把任务/成果/证据切为页签，保留范围和只读标识；状态不能只靠颜色。跳转领域页面携带同一成果上下文并支持回到来源任务。

只读身份必须贯穿页面、公共搜索栏、抽屉、键盘快捷键和后端能力白名单；禁按钮或URL readonly=true 都不是权限边界。具体危险入口与验收证据见 [写入口隔离清单](D:/知识图谱/docs/assistant-team/integration/I1/I1-WRITE-ISOLATION.md)。

本轮只能审核上述信息架构与文案。实际点击、2D/3D高亮、引用重读、无写入和跨页面流程分别待I5/I6/I7实现后验收。
