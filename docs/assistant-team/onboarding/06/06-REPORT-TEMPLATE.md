# 06 执行报告模板（首次只读入职不创建执行报告）

1. 授权：负责人指令、阶段/批次、允许范围、实际停点、未授权内容。
2. 执行身份：06 会话/工作树/分支/HEAD；实际工作、源码、运行、证据目录；用户确认模型的来源/时间，工具未能回读时写实际模型/推理强度未核实。
3. 基线：领域 owner/实际作者，获批文件，主项目前像/后像，依赖与新增路径，治理 overlay，未知修改保护。
4. 实际职责：原任务代码作者/自测者、06 汇集者/测试者/真实验证者、总控审核者分列；复用历史结论不是本次重跑。
5. 测试：命令、唯一 run ID、方法定义数、参数化展开数、去重数、失败/错误/跳过/阻断、每轮结果及重跑原因。不得把红绿轮次相加称新覆盖。
6. 真实环境：版本/UUID/端口/库/datadir/进程，权限/规模/超时，管理/loader/reader 分离；未核实项明确列出，不泄露凭据。
7. 结果：独立预期、实际结果、原始 EXPLAIN、异常堆栈/SQL/参数、逐样本耗时、p95 算法/样本数量/冷热状态，采样度量对象（组合还是单 SQL）。
8. 零写入：各静态窗口数据/DDL/binlog/loader/reader 残留，管理操作与装载写入分开；安全不变量破坏不得报绿。
9. 收尾：实例正常停止、剩余进程/监听、证据保全/索引/hash；失败同样需收尾。
10. 问题整批清单：实际修改与原因、检查未改与原因、待另批事项、拟 owner、未验证内容及下轮前置条件。
11. 技术结果不等于负责人验收，停止，不自行修域代码/派发/续阶段。
