## 交付内容

在本工作树仅新增 `docs/assistant-team/website/08-stage1/` 下 `HTTP-CONTRACT.md`、`http-contract.json`、`HOST-WIRING.md`，及 `docs/assistant-team/reports/08-host-api-stage1.md`。

契约至少明确：能力可用状态、服务端允许选择的库/资料、固定首版任务模板、运行创建/状态/取消、成果与证据、精确原文重读、研究子图读取。保持现有 HTTP 包络，明确 URL、方法、输入/输出、错误及状态。不可用与空结果分开；运行可仅保留内存并明确刷新/重启后限制，不新增数据库迁移或聊天持久化。

固定首版闭环为“读取资料 → 有向图谱研究 → 引用核查”。五个角色并非每次全部出动，首版可用确定性计划调度已有工具，不能将其宣传成已接入真实模型。自由目标输入与模板的关系明确；学习和正式测评可用性不凭前端推断。

所有 ID 在跨语言契约中明确 Long 的安全表示；Scope 各维最多 1000，范围由服务端确定与交叉核验。模板不能让前端自报角色/权限、工具名称或上游成果。引用及成果必须能追溯直接依赖；适配层只传递、转格式，不重算领域判断或排名。

接线方案指出实际存在的注册/宿主缺口、需要的新 Java 文件、默认禁用开关和后续启用条件。只读数据库身份应与既有业务写连接分开，不默默使用应用写账号；本阶段不读凭据。鉴权首版范围具体说明，不虚构现有多用户隔离，不自行采用生产认证方案或增加权限。

供 07/09 使用的字段须能够覆盖任务、成果、来源、范围、观察时间、覆盖缺口和图谱方向。不要为前端制造假来源或假节点，不使用旧全库邻居接口替代授权研究子图。
