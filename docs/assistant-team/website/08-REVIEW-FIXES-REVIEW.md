## 差异及影响核对

1. `sourceFilePresent=false` 不再由宿主否决资料选择/创建；原事实仍投影。处理状态、生命周期、归属与权限没有放宽；正式 chunk 读取与来源不可用仍交原领域判断。新回归用真实 provider/Runtime 与 fake 仓储验证正常原文链及缺口，不是数据库验证。
2. 重读保留领域缺失/不可用/读取中失效/陈旧四类错误，分别映射 404/409/503/409，不返回正文或全库兜底。新增七种前后时序断言；原两处错误旧预期精确替换，归属、hash、权限断言保留。
3. HTTP 输入继续按 UTF-8 字节限制，可信内部 JSON 改按冻结核心的 String 字符边界；内部失败为服务器错误。中文真实工具/成果链、32000 字符边界及超限断言存在，HTTP64KiB/4KiB、核心32000/16000、Scope1000未扩大。
4. 未接入四项能力返回 unavailable 及约定原因；读取开关关闭 disabled、缺身份 unavailable，模型调用0、formalAvailable=false。不是新增学习/测评或模型能力。
5. `HostJson.ids` 的有序校验集合转独立不可变 documentOrder，用于预检和计划；不依赖 Scope Set 顺序。A/B、B/A 两链验证及实际 worker pool=1 断言存在；IO槽位及其它预算未改。
6. 同源/loopback门禁后拒绝 GET 非空 body，原 no-store 保留；七个GET端点拒绝与正常端点回归均保留，无新增路由/授权。
